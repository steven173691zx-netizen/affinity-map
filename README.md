# Affinity

Node-based affinity mapping in a single HTML file: text, sticky, drawing, image, canvas, combine and **journey map** blocks, a magic pencil, a stickman play mode, and live peer-to-peer collaboration (WebRTC via Trystero, no server). Boards are stored in your browser (IndexedDB); export to PDF or Markdown.

Open `index.html`, or visit the published site. Press `/` for all commands and `⇧/` for the shortcut editor.

| Key | Action |
| --- | --- |
| `J` | Align blocks: x with x, y with y (same kind and size only) |
| `O` | Organise a messy board into tidy grids |
| `X` / `Y` | Arrange selection in a row / column |
| `M` | Matrix: spawn a row / column / grid of copies of the selection (count + gap, live preview) |
| `C` / `⇧C` | Combine block / canvas |
| `⌘G` | Group into a canvas |
| `⇧J` | New journey map |
| `B` | Magic pencil |
| `P` | Stickman mode |
| `⇧D` | Themes |
| `E` | Delete empty blocks |
| double-click | New text block, centred on the click (inside a journey cell it is centred in that cell) |
| `⇧E` | Export area to PDF |

**Phone as a remote control (optional)** — on the desktop open *More → Pair a phone…* (or Share) to get a QR code / room code. On the phone choose *Remote control*, pick a desktop from the list and the desktop taps *Allow*. The phone then shows only the format bar (fill, text size, alignment, text colour, undo/redo) for whatever is selected on the desktop, and when a drawing block is selected you can draw on the phone and the strokes appear live. A phone is a remote control only: it does not open the board for editing. Besides the format bar it can step through blocks (Prev / Next), zoom and fit the desktop view, add a text / note / heading / drawing, duplicate / align / delete the selection, type into a selected text block, undo / redo, and pick its own theme.
