# Affinity

Node-based affinity mapping in a single HTML file: text, sticky, drawing, image, canvas, combine and **journey map** blocks, a magic pencil, a stickman play mode, and live peer-to-peer collaboration (WebRTC via Trystero, no server). Boards are stored in your browser (IndexedDB); export to PDF or Markdown.

Open `index.html`, or visit the published site. Press `/` for all commands and `⇧/` for the shortcut editor.

| Key | Action |
| --- | --- |
| `J` | Align blocks: x with x, y with y (same kind and size only) |
| `O` | Organise a messy board into tidy grids |
| `X` / `Y` | Arrange selection in a row / column |
| `M` | Matrix: spawn a row / column / grid of copies of the selection (count + gap, live preview) |
| `C` / `⇧C` | Combine block / canvas |
| `⌘G` | Group into a canvas |
| `⇧J` | New journey map |
| `B` | Magic pencil |
| `P` | Stickman mode |
| `⇧D` | Themes |
| `E` | Delete empty blocks |
| double-click | New text block, centred on the click (inside a journey cell it is centred in that cell) |
| `⇧E` | Export area to PDF |

**Phones and tablets** get a simplified toolbar: Select (box-select), Add (tap or drag Text / Canvas / Heading / Image / Drawing onto the board), Undo, More. Pinch to zoom, one finger to pan, tap a selected text block to edit it.
