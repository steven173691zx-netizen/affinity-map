# Affinity

Node-based affinity mapping in a single HTML file: text, sticky, drawing, image, canvas, combine and **journey map** blocks, a magic pencil, a stickman play mode, and live peer-to-peer collaboration (WebRTC via Trystero, no server). Boards are stored in your browser (IndexedDB); export to PDF or Markdown.

Open `index.html`, or visit the published site. Press `/` for all commands and `⇧/` for the shortcut editor.

| Key | Action |
| --- | --- |
| `J` | Auto-cluster (aligns only when already tidy) |
| `X` / `Y` | Arrange selection in a row / column |
| `⌘G` | Group into a canvas |
| `⇧J` | New journey map |
| `B` | Magic pencil |
| `P` | Stickman mode |
| `⇧D` | Themes |
| `E` | Export area to PDF |
